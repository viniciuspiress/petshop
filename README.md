# PetShop Amigo Fiel - Fase 1

Projeto da disciplina Fundamentos de Sistemas Web.
Desenvolvido por Vinícius da Silva Pires.

## Sobre o projeto
Site de um petshop, construído nesta Fase 1 apenas com HTML (sem CSS, Bootstrap ou JavaScript).

## Páginas
- **index.html**: página inicial, com apresentação do petshop e atalhos para as categorias.
- **produtos.html**: produtos divididos em 3 categorias (acessórios, rações e higiene e limpeza), com 2 itens em cada. Cada item mostra foto, descrição e valor.
- **servicos.html**: tabela com os serviços de banho e banho e tosa, com descrição, valor e opção com ou sem tele-busca.

## Funcionalidades
- Cabeçalho com nome, endereço, telefone e menu de navegação entre as páginas.
- Corpo com produtos e serviços.
- Rodapé com autoria, contato e links de navegação.
- Links no menu inicial que levam direto a cada categoria de produtos.

## Estrutura de arquivos
- index.html
- produtos.html
- servicos.html
- img/ (imagens dos produtos)
- README.md
